# OEL studies

Each folder contains a numerical reproduction of a result from an astrodynamics paper with Orbital Engineering Lab (OEL). The paper’s claim, inputs, assumptions, exact engine pin, replay command and comparison live together so the folder can be used independently.

| Paper | Reproduced result | OEL |
| --- | --- | --- |
| [Schaub & Alfriend (2001)](studies/schaub-alfriend-2001/) | Secular relative-phase drift in the 48° formation example, Figures 3B and 4B | 1.1.0 |

Studies that require an OEL improvement use the exact tested development version and immutable revision. Each study describes its public installation route and which parts of the published analysis it covers.
